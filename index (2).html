Final-year project · Hexilia (AgriTech) · Feb–Aug 2026

Agricultural decision platform

End-to-end BI platform: data warehouse, automated ETL, role-based dashboards and a conversational assistant.
Featured

Problem

Farm data sat in scattered raw files. It was hard to use and brought little value to day-to-day decisions.

Approach

Defined facts, dimensions and grain with an agronomist, then designed a Kimball star schema in PostgreSQL with PostGIS.

Build

Containerized Python ETL with quality checks and rejection logs; Superset dashboards filtered by user role.

Outcome

One trusted source of truth, dashboards for each profile, and questions answered in plain language by an AI assistant.

Simplified, illustrative view of the dimensional model behind the dashboards.
